# سامانه کلاس قرآن

## وضعیت فعلی
رابط سایت به Firebase Authentication، Firestore، Cloud Functions و Cloud Storage متصل شده است. فایل‌های پیکربندی و قوانین امنیتی نیز در مخزن قرار دارند. **این مخزن به‌تنهایی به معنی استقرار سرویس‌ها نیست**؛ مراحل زیر باید در پروژه Firebase اجرا شوند.

## پیش‌نیازهای یک‌باره در Firebase
1. در پروژه `quran-calss-604db`، سرویس Authentication را فعال و روش **Email/Password** را روشن کنید.
2. یک پایگاه داده Cloud Firestore بسازید.
3. سرویس Cloud Storage را راه‌اندازی کنید.
4. مطمئن شوید پروژه امکان استفاده از Cloud Functions و طرح پرداخت موردنیاز Firebase را دارد.

## استقرار
روی رایانه‌ای که Node.js 20 و Firebase CLI نصب است:

```bash
npm install -g firebase-tools
firebase login
git clone https://github.com/erfantmbx2009-droid/quran-class.git
cd quran-class
cd functions && npm install && cd ..
firebase use quran-calss-604db
firebase functions:secrets:set ADMIN_SETUP_CODE
firebase deploy
```

هنگام تنظیم secret، یک عبارت تصادفی و قوی انتخاب کنید. آن را در کد سایت، GitHub یا پیام عمومی قرار ندهید. فقط همان عبارت را در فرم «راه‌اندازی مدیر اولیه» وارد کنید. این عملیات فقط یک بار موفق می‌شود؛ پس از ساخت مدیر، کد راه‌اندازی را محرمانه نگه دارید و در صورت نیاز secret را حذف/تعویض کنید.

پس از استقرار، سایت GitHub Pages از طریق فایل `index.html` به Firebase وصل می‌شود. اگر GitHub Pages هنوز فعال نیست، در تنظیمات مخزن از شاخه `main` و پوشه ریشه برای Pages استفاده کنید.

## نقش‌ها
- مدیر: ساخت حساب دانش‌آموز و مربی
- مربی: انتشار تکلیف/اطلاعیه، بارگذاری مطالب و مشاهده گزارش حضور
- دانش‌آموز: ثبت حضور روزانه و مشاهده تکالیف و فایل‌ها

نام کاربری باید ۳ تا ۲۴ نویسه و شامل حروف انگلیسی کوچک، عدد یا زیرخط باشد. رمز عبور حداقل ۸ نویسه است.

## نکات امنیتی و محدودیت‌های نسخه فعلی
- ایجاد حساب‌ها و ثبت حضور از طریق Cloud Functions انجام می‌شود؛ کاربر نمی‌تواند مستقیماً نقش خود را در پروفایل تغییر دهد.
- قوانین Firestore و Storage باید پیش از استفاده عمومی مستقر شوند.
- ثبت حضور بر اساس روز تقویمی ایران است و برای هر دانش‌آموز در هر روز یک رکورد دارد.
- قبل از استفاده واقعی، قوانین و فرایندها را با حساب آزمایشی دانش‌آموز، مربی و مدیر بررسی کنید.
- اطلاعات حساس، رمزها و کلیدهای سرویس Firebase Admin نباید در مخزن قرار بگیرند.
- نسخه فعلی بخش تکالیف و مطالب آموزشی پایه را دارد؛ تحویل تکلیف دانش‌آموز و مدیریت کامل کاربران هنوز پیاده‌سازی نشده است.
